# Tableau過去問道場

添付の「択一・複数回答形式練習問題.xlsx」をもとにした日本語の学習アプリです。157問、正答・解説、問題と解説の図版、「メモ」「グラフ特徴」を収録しています。

## 起動

Python 3 がある環境で、このリポジトリ内から実行します。追加パッケージのインストールは不要です。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで同じマシンのポート8000にアクセスしてください。静的ファイルだけで動作し、API、CDN、外部フォント、外部サービスへの通信はありません。通常の静的Webホスティングにも配置できます。

## 機能

- ○×・単一選択・複数選択（複数選択は順不同の完全一致で採点）
- 正答、解説、添付の図版の表示
- 全問・間違えた問題・未回答の絞り込み、番号・問題文・選択肢の検索
- シャッフル、問題番号による移動、再回答
- 回答履歴と正答率のブラウザ内保存、確認付きリセット
- 学習メモ・グラフ特徴の閲覧、スマートフォン向け表示

学習履歴はこのブラウザの localStorage に保存されます。サーバーへの送信や端末間同期はありません。保存が禁止されたブラウザでは画面上で警告し、その画面内で利用できます。

## 資料の扱い

正答・解説は原本のままで、最新のTableau仕様への修正はしていません。ふりがな情報は本文から除外しました。参照URLは解説の文字列として表示し、自動接続しません。原本にアプリの詳細な画面仕様はないため、演習・採点・復習の標準的な流れを実装しています。

原本の70問目は4番目の選択肢が「③」と重複しているため、アプリでは「④」として区別し、画面にも補正理由を表示します。正答「①③」は解説に従って維持しています。

元のExcelはリポジトリに複製していません。配布データ `data.js` と `assets/` は取込済みです。Excelを更新した場合は、そのファイルへのパスを指定して再取込できます（Python標準ライブラリのみ使用）。

```sh
python3 tools/import_workbook.py '/path/to/択一・複数回答形式練習問題.xlsx'
```

## 検証

```sh
node --check app.js
node tests/data.cjs
```

ブラウザテストは Playwright と Chromium が導入済みの開発環境用です。アプリの実行には不要です。上記サーバーの起動後に実行します。

```sh
node tests/browser.cjs
```

このクラウド環境の既存ツールを使用して検証しています。ブラウザテストの Chromium のパスは `/usr/bin/chromium` です。

## 回答前の解説と復習

「わからない・解説を見る」で回答前に正答・解説・図版を表示できます。解説を見た問題と不正解の問題は「要復習」に保存されます。出題範囲から「要復習」を選び、「もう一度解く」で再挑戦してください。解説を見ずに正解すると要復習から外れます。解説を見るだけでは回答済みや正答率は変わりません。再挑戦中も過去の採点結果と要復習状態は保持します。

復習対象は問題番号ごとに1件だけ保存されます。同じ問題を何度間違えたり解説を開いたりしても重複しません。「復習リストをリセット」は確認後に復習対象だけを空にします。回答履歴と正答率は維持され、再読み込み後も解除状態を保持します。新たに間違えたり解説を見たりすると再登録されます。

「番号順（昇順）」で、シャッフルした問題を番号の小さい順に戻せます。出題範囲と検索条件は維持し、該当する最初の問題を表示します。

「問題一覧を閉じる」で QUESTION INDEX を折りたたみ、問題欄を広く表示できます。「問題一覧を開く」で元に戻せます。スマートフォンでも利用できます。
